# onivue-resume

## Create your modern CV with ease

A free, open-source resume and cover letter builder with client-side PDF generation, built with the latest web technologies.

---

## 🚀 [Live Demo](https://resume.onivue.ch/)

## 📖 About

onivue-resume is a modern web application that allows you to create professional resumes and cover letters directly in your browser. All PDF generation happens client-side, ensuring your personal information never leaves your device.

## ✨ Features

- **Client-side PDF generation** with @react-pdf/renderer - Your data stays private
- **Dual document creation** - Build both resumes and cover letters
- **Modular block system** - Customize your documents with flexible content blocks
- **Image support** - Add photos to your documents
- **Dark mode** - Comfortable viewing in any lighting condition
- **Modern UI** - Clean, responsive design with retrobrutalist influences
- **Persistent storage** - Your work is saved automatically in your browser

## 🚀 Getting Started

### Prerequisites

- Node.js 20.x or later
- npm 10.x or later

### Installation

```bash
# Clone the repository
git clone https://github.com/onivue/onivue-resume.git

# Navigate to the project directory
cd onivue-resume

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

- `npm run dev` – Start development server
- `npm run build` – Build for production
- `npm start` – Start production server
- `npm run lint` – Check code with Biome
- `npm run lint:fix` – Fix code issues with Biome
- `npm run format` – Format code with Biome
